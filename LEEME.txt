CFB RANKING STUDIO - Edición preparada para Netlify

IMPORTANTE: Esta versión necesita publicarse en Netlify con la función de servidor incluida.
NO abras index.html directamente: el botón de actualización no funcionará sin /api/espn.

PUBLICACIÓN RECOMENDADA (requiere cuentas gratuitas en GitHub y Netlify):
1. Descomprime este ZIP.
2. En GitHub crea un repositorio nuevo, por ejemplo 'cfb-ranking-studio'.
3. Usa 'Add file > Upload files' en el repositorio y sube:
   - index.html
   - netlify.toml
   - la carpeta netlify/functions con espn.mjs (respetando la ruta)
   Atención: desde la web de GitHub puede ser más fácil arrastrar la carpeta completa.
4. En Netlify elige 'Add new project > Import an existing project > GitHub'.
5. Selecciona el repositorio. Publicación: raíz del repositorio; funciones: netlify/functions.
6. Pulsa Deploy. La dirección gratuita acabará en netlify.app.
7. Abre la URL publicada y prueba actualizar.

DIAGNÓSTICO:
- Si aparecen balances, el acceso mediante la función está funcionando.
- Si muestra 'ESPN también ha rechazado la petición del servidor (403)', será necesario usar
  otra fuente de datos autorizada. Netlify no puede garantizar acceso a ESPN.

DATOS GUARDADOS:
Los rankings previos almacenados en el navegador bajo file:// NO se trasladan
necesariamente a la web. Conserva los archivos y exporta una copia JSON de tus rankings.

Esta versión no requiere clave API pero depende de endpoints ESPN no oficiales.
